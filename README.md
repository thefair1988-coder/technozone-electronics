# טכנוזון חשמל אונליין

חנות אלקטרוניקה וחשמל (React + TypeScript + Vite + Tailwind CSS), עם קטגוריות
מוצרים, עגלת קניות, צ'קאאוט ופאנל ניהול. ריפו עצמאי לגמרי — אין לו שום קשר
לפרויקט, לחשבון או למערכת אחרת.

## הרצה מקומית

```sh
git clone <repository-url>
cd technozone-electronics
bun install
bun run dev
```

## סקריפטים

- `bun run dev` — שרת פיתוח
- `bun run build` — בנייה לפרודקשן ל-`dist/`
- `bun run lint` — ESLint + Prettier
- `bun run typecheck` — בדיקת טיפוסים
- `bun run test` — בדיקות Vitest
- `bun run verify` — כל הבדיקות ברצף (typecheck, lint, test, build)

## כניסה לפאנל הניהול

`/admin` — ברירת מחדל: משתמש `admin`, סיסמה `admin123`.
ניתן (ומומלץ לפני פרסום אמיתי) לשנות באמצעות משתני סביבה בזמן build:

```sh
VITE_ADMIN_USERNAME=your-username
VITE_ADMIN_PASSWORD=your-strong-password
```

**חשוב:** זו הגנה בצד הלקוח בלבד (מתאימה לשלב הדמו/נתונים-בקוד הנוכחי) —
אינה תחליף לאימות אמיתי בפרודקשן.

## איך שמורים הנתונים

מוצרים וקטגוריות מגיעים מ-`src/data/{products,categories}.ts` (seed קבוע
בקוד) ונטענים פעם ראשונה ל-`localStorage`. מרגע זה כל שינוי — כולל הוספה/
עריכה/מחיקה של מוצרים וקטגוריות דרך פאנל הניהול, עגלת הקניות וההזמנות —
נשמר ונקרא מ-`localStorage` באותו דפדפן. המשמעות:

- נתונים **לא** מסונכרנים בין מכשירים/דפדפנים שונים.
- ניקוי נתוני האתר בדפדפן מאפס בחזרה לנתוני ה-seed המקוריים.
- להחלפה עתידית ב-DB אמיתי: כל הגישה לנתונים עוברת דרך
  `src/state/{CatalogContext,CartContext,OrdersContext}.tsx` — אפשר להחליף
  את המימוש הפנימי (localStorage → API) בלי לשנות את שכבת ה-UI.
